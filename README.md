# Customer Spending Prediction Using Linear Regression

## Project Overview
This project uses Linear Regression to predict customer spending based on purchase frequency.

## Dataset
The dataset contains customer spending and purchase frequency information.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Objective
To analyze customer spending patterns and build a predictive model.

## Conclusion
The model predicts customer spending using purchase frequency and demonstrates the application of Linear Regression in machine learning.
